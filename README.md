# Onchain Rewind

Your wallet's year, played back.

A web app that reads a wallet's public onchain history from the [Zerion API](https://developers.zerion.io) and plays it back as a cinematic story: a particle reveal driven by the real transactions loading, five animated cards, and a shareable summary.

- Product and architecture: [SPEC.md](SPEC.md)
- Agent instructions: [AGENTS.md](AGENTS.md) (Codex and others) and [CLAUDE.md](CLAUDE.md) (Claude Code)
- Design handoff: [design/](design/)

**Stack:** TanStack Start, React 19, TypeScript, Tailwind CSS v4, Ariakit, Motion, Canvas 2D.
